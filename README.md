# Jin.Dev Portfolio

A personal portfolio website built with Next.js, featuring an integrated AI chatbot for interactive project exploration.

---

## 🧭 Overview

This project is a personal portfolio site designed to present projects and skills in an interactive way.
In addition to standard portfolio sections, it includes an **AI-powered chatbot** that allows visitors to ask questions about projects, tech stack, and experience.

The focus of this project is not visual polish alone, but **frontend architecture, state management, and practical AI integration** in a real web application.

## ✨ Key Features

### 🤖 AI Chatbot Integration

- Embedded AI chatbot powered by **Google Gemini API**
- Answers questions about:
  - featured projects
  - technologies used
  - overall experience
- Context-aware responses based on portfolio content
- Implemented as a real UI feature, not a standalone demo

### 🖥 Frontend Architecture

- Built with **Next.js** and **TypeScript**
- App Router–based layout and component structure
- Modular UI components for reuse and maintainability
- State-driven UI updates and interactions

### 🎨 UI & Interaction

- Responsive layout for desktop and mobile
- Smooth animations using **Framer Motion**
- Dark / Light mode support
- Scroll-based navigation and section highlighting

---

## 🛠 Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Frontend:** React
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **AI / LLM:** Google Gemini API
- **Deployment:** Vercel
